# Day 16 提升复购模型与概率校准设计

## 目标

在无时间泄漏的首单特征集上比较 Random Forest、LightGBM 与 Logistic Regression，选择更优的客户排序模型，并将其分数校准为可解释的复购概率。

## 时间隔离

数据按预测时点依次划分为训练期、模型选择期、校准期和最终测试期。训练期仅用于拟合；选择期仅用于比较候选的 PR-AUC 与 Lift@10%；校准期只用于拟合概率映射；最终测试期从不参与前述环节，只在流程结束时评估一次。

## 候选与选择

三种候选使用同一组 Day 14 特征。LightGBM 使用早停抑制过拟合，Random Forest 作为树模型参照，Logistic Regression 作为线性基线。选择指标以 PR-AUC 为主、Lift@10% 为营销资源约束下的业务补充；不以 Accuracy 选模型。

## 校准与解释

对选择出的候选模型，以校准期分数训练 sigmoid 概率映射；输出校准前后的 Brier score。树模型输出特征重要性，并记录五个代表客户的输入特征和预测分数；不将相关性解释为因果影响。

## 产物与验收

保存候选结果、选中模型、特征 schema、校准结果与模型卡。最终测试集必须如实报告是否超过首单金额业务规则；若未超过，同样保留结果和限制说明。
