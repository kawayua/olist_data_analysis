# Dashboard 中文展示标签设计

## 目标

Dashboard 中所有面向读者的表格列名、图表横纵轴、图例和悬停提示均使用中文业务口径。数据仓库、SQL 查询和 DataFrame 内部字段继续保留英文，避免影响现有分析逻辑。

## 方案

展示层以 `app/components/presentation.py` 为唯一中文化入口：

- 为五个分析页面实际展示的所有字段补全中文列名。
- 为客户分群、复购间隔等枚举型值提供中文显示值映射。
- `display_dataframe` 返回副本，翻译列名及已定义的分类值，不修改查询结果。
- 图表工厂通过同一映射生成横纵轴和图例标题；悬停提示按金额、百分比、评分、数量使用对应中文名称及格式。

## 边界

不修改 SQL 集市、仓库查询、指标计算或筛选逻辑。本次不改变图表种类和页面布局。

## 验收与测试

- 单元测试覆盖新增字段和分类值的表格展示翻译。
- 图表测试断言横轴、纵轴、图例及悬停字段使用中文标签。
- 运行可视化测试套件、代码检查，并启动 Dashboard 验证页面可加载。
