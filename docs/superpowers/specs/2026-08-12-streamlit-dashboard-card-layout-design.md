# Streamlit 卡片化数据驾驶舱设计

## 目标与范围

将 `app/` 中的 Olist 电商分析应用从基础纵向页面升级为专业、克制的卡片化数据驾驶舱。改造覆盖主页、五个分析页、共享筛选器、KPI 展示和 Plotly 图表辅助代码；不改动 SQL、仓储查询、指标计算或底层 DataFrame 字段名。

## 视觉系统

界面使用浅灰蓝背景、白色内容卡片、深蓝主色和琥珀色预警色。页面采用紧凑的仪表盘密度：标题区提供页面定位和数据口径，核心指标置于同一行，分析内容置于两栏或三栏卡片网格，明细数据位于独立卡片内。所有文本保持可读对比度，关键状态不能只靠颜色表达。

## 页面和组件架构

新增共享主题模块，集中注入 Streamlit CSS、页面标题、内容卡片和洞察提示的渲染能力。KPI 组件改为自定义卡片，显示指标名称、主数值与辅助说明。筛选器在侧栏中按“时间范围”“分析维度”“数据口径”分组，并保留可见标签和帮助信息。

各页面复用统一骨架：页面标题与说明、KPI 卡片、图表和解释卡片、明细表格。经营总览、客户价值、商品与履约页面使用排名条形图；增长页保留趋势线；留存页使用带色阶的 Cohort 热力图。图表和表格继续以仓储返回的数据为来源。

## 中文展示映射

底层字段保持英文。共享展示层负责将用户可见内容转换为中文，包括：`item_revenue` 为“商品金额”、`order_count` 为“订单数”、`customer_count` 为“客户数”、`customer_state` 为“客户所在州”、`product_category` 为“商品品类”、`customer_segment` 为“客户分群”、`delivery_status` 为“履约状态”、`average_review_score` 为“平均评分”、`month_start` 为“月份”、`retention_rate_pct` 为“留存率（%）”。

Plotly 图表必须为标题、坐标轴、图例、悬浮提示及文本标签配置中文名称和数值格式；Streamlit 数据表在显示前重命名列名，内部计算继续使用原字段。排序类柱状图按业务指标降序显示，并在条形上展示数值。

## 验收与验证

1. 五个页面可正常加载，并保持现有筛选及空数据处理行为。
2. 所有图表和表格中可见字段为中文，无英文技术列名泄漏。
3. 图表标题、坐标轴、图例、悬浮提示和数值格式完整且一致。
4. 窄屏下页面不产生横向溢出，侧边栏和主要内容仍可使用。
5. 运行现有测试及新增展示层测试，检查格式、字段映射和图表配置。
