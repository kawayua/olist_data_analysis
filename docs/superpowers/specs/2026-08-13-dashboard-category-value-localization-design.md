# Dashboard 品类值中文化设计

## 目标

将 Dashboard 中 Olist 的英文品类编码统一显示为中文品类名，覆盖经营总览、留存复购、商品与履约页面的图表、图例和表格。

## 方案

在 `app/components/presentation.py` 增加完整的英文品类编码至中文品类名映射，并由 `display_value` 同时应用到 `product_category` 与 `first_purchase_category`。图表工厂会对作为横轴或图例的分类字段创建中文展示副本，表格继续使用同一展示层。

## 边界

不修改数据库表、SQL 集市、查询结果中的原始品类编码、筛选逻辑或指标计算。未知编码原样显示，以避免错误归类。

## 验收

- 核心品类 Top 10、首购品类 90 天复购率的横轴值显示中文。
- 首购品类复购明细的品类值显示中文。
- 商品金额与订单量气泡图的品类图例显示中文。
- 自动化测试覆盖表格、柱状图和气泡图的品类值映射。
