# Streamlit 悬浮吸顶导航设计

## 目标

以一条专业、克制的顶部悬浮导航替代 Streamlit 默认多页侧边栏菜单，同时保留现有的筛选侧栏。导航在所有主页和分析页保持一致，并在滚动时固定于视口顶部。

## 路由与组件

新增 `app.components.navigation` 作为唯一导航组件。`render_navigation()` 使用 Streamlit 原生 `st.page_link` 仅生成五个分析页链接，保持现有路由、当前页状态与键盘访问能力。所有页面在主题注入后、正文标题前调用该组件。`Home.py` 保留为应用启动入口，但不作为导航页展示。

## 视觉与交互

导航距视口顶部 12px，采用半透明白色背景、轻阴影、圆角和深蓝主色。当前页链接使用深蓝实底与白色文字；其余链接在悬停和键盘聚焦时显示浅蓝背景和可见焦点环。窄屏下链接自动换行，避免横向滚动。CSS 只隐藏默认的页面导航区域，不隐藏筛选侧栏或其控件。

## 验收

1. 首页和五个分析页均调用共享导航组件。
2. 默认 Streamlit 多页菜单不可见，筛选侧栏仍可见。
3. 导航仅包含五个分析页，链接使用现有文件路由，不展示首页入口。
4. 样式包含 sticky 定位、浮动间距、当前页、悬停、焦点和窄屏规则。
5. 新增测试验证导航链接和所有页面接入；运行 pytest 与 Ruff。
