# Day 14：时间安全的 90 天复购训练集

`marts.customer_360` 是数据结束日的全量快照，含后续订单、累计消费和最终 RFM，不能直接用于首单时点的复购预测。新的 `marts.ml_customer_features` 固定为一位客户一行，预测时点 `prediction_time` 为首单实际送达时间；特征仅来自首单商品件数、商品金额、运费、支付金额、品类数与配送时长，`feature_available_at` 与预测时点相同，便于审计。

标签窗口是 `(prediction_time, prediction_time + 90 days]`：首单送达后 90 天内出现另一笔已送达订单即为正例。观察终点不足完整 90 天的客户标记为 `eligible_for_90d = false`，不能进入训练、验证或测试。实际验证得到 82,500 位完整观察期客户，90 天复购率约为 1.095%；另有 10,850 位末端观察期不完整客户被排除。

这是一项类别不平衡任务，Day 15 应优先关注 PR-AUC、Lift@K 等排序指标，而不能只看 Accuracy。训练、验证和测试必须按 `prediction_time` 前后切分；随机切分会让同一时期的模式同时出现在训练和测试中，使离线结果偏乐观，不能代表用历史预测未来的真实场景。
