# 项目统计学方法说明

本项目的统计分析目标是把业务现象转换为可复现、可解释、并且边界明确的证据。报告不会只给出一个 p 值；每次比较应同时报告样本量、点估计、效应量或绝对差、置信区间、检验结果和因果限制。

## 1. 描述统计：先说明数据长什么样

项目使用订单数、客户数、商品金额、比例、均值、中位数和分位数描述增长、履约、评分与复购。均值适合说明整体水平，但商品金额和配送时长通常右偏、易受极端值影响，因此同时报告中位数；例如延迟订单的平均配送时长为 31.519 天、中位数为 29.155 天，按时订单分别为 10.884 天和 9.727 天。

描述统计回答“发生了什么”，但本身不证明差异不是随机波动，也不证明因果。

## 2. 复购率与 Wilson 95% 置信区间

90 天复购率定义为：具有完整 90 天观察期的首购客户中，在首购后 90 天内再次完成已送达订单的比例。`marts.repurchase_horizons` 对 30/60/90 天复购率使用 Wilson 95% 置信区间。

Wilson 区间适用于二元结果（复购/未复购），特别适合低复购率；它比简单正态近似更稳定。区间表示在重复抽样框架下，未知总体比例的合理范围，而不是“95% 的客户会落在区间内”。例如 90 天复购率为 2.008%，区间为 [1.911%, 2.111%]，说明点估计存在抽样不确定性。

## 3. 两独立比例比较：首购按时与延迟履约的 90 天复购

`compare_binary_proportions` 比较两个独立客户组的二元结果。group 0 定义为按时首购，group 1 定义为延迟首购；输出两个复购率、绝对差（group 1 - group 0）、相对差、比例差的 Wald 95% 区间，以及双侧 Fisher 精确检验 p 值。

Fisher 精确检验不依赖大样本卡方近似，对低发生率或某些分组较小时更稳妥。比例差区间使用标准误近似，因此报告时必须和 Fisher p 值、实际样本量一起解读。

真实结果：按时首购客户为 68,778 人，其中 1,394 人复购，复购率 2.027%；延迟首购客户为 6,609 人，其中 120 人复购，复购率 1.816%。延迟减按时的绝对差为 -0.211 个百分点，相对差 -10.4%，95% 区间 [-0.550, 0.128] 个百分点，双侧 Fisher `p = 0.251`。区间跨越 0 且 p 值大于 0.05，因此不能拒绝“两组总体复购率相同”的原假设；当前样本对复购率差异没有提供统计显著证据。

这不等于证明两组完全相同，也不表示延迟没有业务影响；它表示本数据和该比较口径下的不确定性仍覆盖零差异。

## 4. Mann–Whitney U：比较偏态或有界评分的两组分布

评分为 1–5 的有界离散数据，配送时长和金额也常偏态，因此项目对两独立组的连续或有序结果默认使用双侧 Mann–Whitney U，而不要求正态分布。该方法把所有观测排序，检验两组的秩是否系统性不同；它不是“只比较中位数”的检验，而是检验分布位置/排序优势是否有差异。

在履约评分分析中，group 0 是按时订单、group 1 是延迟订单。排除缺失评分后，按时组 88,171 笔、延迟组 7,661 笔；评分中位数分别为 5 与 2。双侧检验 p 值小到浮点数下溢，应写为 `p < 5 × 10^-324`，而不是写成 p 等于 0。这是延迟组评分分布较低的极强关联证据。

## 5. 秩二列相关：Mann–Whitney U 的效应量

仅有 p 值无法回答差异有多大。项目用秩二列相关表示 group 1 相对 group 0 的排序优势，范围为 -1 至 1：0 表示没有系统性秩优势；正值表示 group 1 整体更高；负值表示 group 1 整体更低。延迟评分分析的值为 -0.554，说明延迟组评分具有明显的整体劣势，而不只是极大样本导致的“显著”。

## 6. Bootstrap 中位数差 95% 区间

项目对评分等数值结果使用固定随机种子、2,000 次重采样的 percentile bootstrap，估计中位数差的 95% 区间。它反复从每组有放回抽样、计算中位数差，再取 2.5% 与 97.5% 分位数；固定种子确保测试和报告可复现。

在评分案例中，延迟减按时的中位数差为 -3 分，区间 [-3, -3]。这反映样本很大且评分差异稳定，但并不消除选择偏差或混杂。

## 7. 如何得出合格结论

一次合格的业务统计结论应按以下顺序表达：现象、证据、限制、行动建议。例如：延迟订单评分中位数比按时订单低 3 分，Mann–Whitney U 显示差异显著且秩二列相关为 -0.554；但品类、卖家、地区与时间没有控制，因此不能说延迟“导致”低评分；可以据此优先设计履约预警与补偿实验，再评估其增量效果。

本项目的历史交易数据没有随机分配、营销触达、成本、库存或利润数据。因此所有当前比较均为关联分析；因果主张必须依赖 A/B 测试、可信的准实验设计或充分说明的调整模型。
