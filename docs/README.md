# 项目文档导航 / Documentation Guide

本目录存放 Olist 电商数据分析平台的正式项目文档。运行缓存、测试临时目录和 Agent 执行记录不属于交付文档，统一保留在仓库根目录的隐藏工具目录中，不在此处归档。

This directory contains the official project documentation for the Olist analytics platform. Runtime caches, temporary test folders, and agent execution records remain in hidden tool directories at the repository root and are not delivery documents.

## 文档边界 / Documentation boundary

以下根目录隐藏项不是正式文档，无需阅读或提交：

- `.git/`：Git 版本控制元数据。
- `.venv/`：本地 Python 虚拟环境与已安装依赖。
- `.streamlit/`：Streamlit 本地配置。
- `.pytest_cache/`、`.pytest-tmp/`、`.pytest-basetemp/`、`.pytest-task2/`：pytest 缓存和临时测试目录。
- `.ruff_cache/`：Ruff 静态检查缓存。
- `.superpowers/`：Codex/Superpowers 的临时任务简报、审查记录与测试工作区；不属于项目交付材料。
- `.worktrees/`：Git 工作树工具目录；不属于项目交付材料。

Do not treat these hidden directories as project documentation. They can be regenerated by local tools and may contain machine-specific or temporary files.
